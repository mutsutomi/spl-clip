# spl-clip — 盛り上がった瞬間を自動で切り出すツール

長時間のゲーム録画などから、**音が大きく盛り上がった瞬間(歓声・叫び声・派手な効果音など)を自動で見つけて、その前後を短いクリップ動画として切り出す**ツールです。

「2時間の録画を全部見返してハイライトを探す」作業を、ブラウザ上の操作画面だけで終わらせることを目指しています。

## こんなことができます

- 録画ファイル(.mov / .mp4 / .mkv など)を選ぶと、音量が特に大きかった瞬間を自動で検出します
- 音量の推移をグラフで見ながら、**スライダーで検出の強さを調整**できます
- 検出した瞬間の前後(標準では60秒ずつ)をクリップとして `clips/` フォルダに書き出します
- 切り出しは無劣化(再エンコードなし)なので、高速で画質も落ちません

## 準備(最初の1回だけ)

### 1. ffmpeg をインストールする

動画の処理に [ffmpeg](https://ffmpeg.org/) という無料ツールを使います。Mac なら「ターミナル」アプリを開いて、次の1行を貼り付けて Enter を押してください。

```bash
brew install ffmpeg
```

> `brew` が入っていないと言われた場合は、先に [Homebrew](https://brew.sh/ja/) をインストールしてください(公式サイトの手順どおりに1行実行するだけです)。

### 2. Python の環境を用意する

このフォルダ(`spl-clip`)でターミナルを開いて、次を順番に実行してください。

```bash
python3 -m venv venv
source venv/bin/activate
pip install numpy streamlit
```

> **venv とは?** このフォルダ専用の Python 環境です。パソコン全体を汚さずにライブラリを入れられます。

準備はこれで完了です。**次回からはターミナルを開く必要はありません。**

## 使い方

### 起動する

**`起動.command` をダブルクリックしてください。** 黒いウィンドウが開いたあと、ブラウザに操作画面が表示されます。

> 黒いウィンドウは動いている間ずっと出しておく必要があります(閉じるとツールも止まります)。終わるときは、そのウィンドウを閉じるか `Control + C` を押してください。

> **Windows の方は `起動.bat` をダブルクリックしてください。** 詳しくは末尾の「Windows で使う」を開いてください。

### ① 動画を選ぶ

「📁 参照」ボタンを押すと、いつものファイル選択ダイアログが開きます。パソコンの中のどこにある動画でも選べます。パスを直接貼り付けても構いません。

動画を選ぶと、**その動画に入っている音声トラックが自動で調べられます。** 音声が1本だけの動画(iPhone で撮った動画など、ほとんどの場合)は何も選ぶ必要がなく、そのまま次に進めます。

OBS などで「ゲーム音」と「マイク音」を分けて録画した動画の場合だけ、どの音で判定するかを選ぶ欄が出ます。**マイクだけのトラックを選ぶと、ゲーム音や BGM に埋もれずに自分の声(叫び)で検出できる**ので、ハイライトの精度が上がります。

### ② 切り出し方を決める

4つのスライダーで調整します。動かすとすぐ下の結果に反映されます。

| スライダー | 意味 | 標準値 |
|---|---|---|
| しきい値(上位%) | 音量が上位何%なら盛り上がりとみなすか。**左に動かすほど候補が増えます** | 99.5 |
| 何秒前から | 検出した瞬間の何秒前から切り出すか | 60 |
| 何秒後まで | 検出した瞬間の何秒後まで切り出すか | 60 |
| まとめる間隔 | 盛り上がり同士がこの秒数以内なら1本のクリップにまとめる | 10 |

### ③ 結果を見る

**音量の推移グラフ**が表示されます。青い線が音量、破線が現在のしきい値、塗りつぶした帯が実際に切り出される範囲です。

スライダーを動かすと破線が上下し、帯の位置と数が変わります。**「しきい値をここまで下げると、これだけ拾える」が目で見て分かる**ので、ここを見ながら調整するのが一番の近道です。グラフの下には、クリップ候補の開始・終了時刻の一覧も出ます。

### ④ 書き出す

「〇本のクリップを書き出す」ボタンを押すと、進み具合を表示しながら書き出します。完成したファイルは `clips/` フォルダに入ります。

```
clips/
  clip_001_000320.mp4   ← 「00:03:20 から始まるクリップ」という意味
  clip_002_001240.mp4
```

### ⑤ 中身を確認する

書き出したクリップは、画面上でそのまま再生して確認できます。「📂 フォルダを開く」ボタンで Finder を開くこともできます。

> ここで再生できないことがありますが、**ファイルが壊れているわけではありません。** iPhone の録画などはブラウザが対応していない形式で保存されているためです。その場合は「📂 フォルダを開く」から QuickTime で確認してください。

## 作業ファイル(キャッシュ)について

音量を調べるために、動画から音声だけを取り出したファイルを `cache/` フォルダに保存しています。これがあるおかげで、スライダーを何度動かしてもすぐ結果が出ます。

ただし**動画1時間あたり約110MBあり、自動では消えません。** 画面の一番下にある「🗂 作業ファイル(キャッシュ)」を開くと、いま何MB使っているかが見え、その場で削除できます。

- **今使っていない〇個を削除** — いま開いている動画のぶんは残すので、待ち時間なしで掃除できます。普段はこちらで十分です
- **すべて削除** — いま開いている動画も取り込み直しになります(確認画面が出ます)

消しても次に使うときに自動で作り直されるので、**いつ消しても大丈夫**です。

## フォルダの説明

| フォルダ | 中身 | 消していい? |
|---|---|---|
| `clips/` | 完成したクリップ動画(成果物) | 必要なものを残して整理 OK |
| `cache/` | 検出用の音声ファイル(作業用) | いつ消しても OK(次回また自動で作られます) |

## 困ったときは

- **起動ファイル(`起動.command` / `起動.bat`)をダブルクリックしても何も起きない** → 「準備」がまだ終わっていない可能性があります。黒いウィンドウに出ているメッセージを確認してください。
- **「ffmpeg が見つかりません」と出る** → 準備の手順 1 を実行してください。
- **候補が多すぎる / 少なすぎる** → 「しきい値」スライダーを右(少なく)か左(多く)に動かしてください。
- **静かな場面ばかり検出される** → BGM や環境音が大きい録画で起こりがちです。OBS でマイクを別トラックにして録画しておくと、①でマイクのトラックを選べるようになり精度が上がります。
- **クリップの開始位置が数秒ズレる** → 無劣化で切り出す都合上、カット位置が動画のキーフレーム単位に丸められるためです。正確さより速度と画質を優先しています。
- **画面右上の「Deploy」は何?** → 土台にしている Streamlit というライブラリが標準で付けているボタンで、このツールとは関係ありません。押す必要はありません。

<details>
<summary><b>コマンドで操作する(上級者向け)</b></summary>

画面を使わず、ターミナルから直接実行することもできます。同じ検出ロジックを使っているので、結果は画面版と同じになります。大量の動画をまとめて処理したい場合などに向いています。

### 準備

ターミナルでこのフォルダを開き、専用環境を有効にします。

```bash
cd spl-clip のフォルダの場所
source venv/bin/activate
```

(行の先頭に `(venv)` と表示されていれば OK です)

### まずは候補を確認する

`--dry-run` を付けると、切り出さずに候補の一覧だけ表示します。

```bash
python3 auto_clip.py 録画ファイル.mov --dry-run
```

```
=== クリップ候補: 5 件 ===
  clip_001: 00:03:20 〜 00:05:20 (120秒)
  clip_002: 00:12:40 〜 00:14:40 (120秒)
```

候補が少なすぎるときは `--percentile` を下げます(標準 99.5 → 99 で上位1%)。多すぎるときは上げます。

```bash
python3 auto_clip.py 録画ファイル.mov --dry-run --percentile 99
```

### 切り出しを実行する

`--dry-run` を外すだけです。

```bash
python3 auto_clip.py 録画ファイル.mov
```

### オプション一覧

| オプション | 意味 | 標準値 |
|---|---|---|
| `--dry-run` | 切り出さず、候補の一覧だけ表示する | — |
| `--percentile 99` | 検出のしきい値。小さくすると候補が増える | 99.5 |
| `--before 30` | 検出した瞬間の何秒**前**から切り出すか | 60 |
| `--after 30` | 検出した瞬間の何秒**後**まで切り出すか | 60 |
| `--gap 30` | 盛り上がり同士がこの秒数以内なら1本にまとめる | 10 |
| `--track 1` | 使う音声トラックの番号(0始まり) | 0 |
| `--out-dir` | クリップの出力先フォルダ | `clips` |
| `--cache-dir` | 作業ファイルの置き場所 | `cache` |
| `--refresh-audio` | 音声の解析キャッシュを作り直す | — |

### マルチトラック録画を使う場合

存在しないトラック番号を指定すると、その動画にあるトラックの一覧を表示して止まります。

```
$ python3 auto_clip.py 録画.mkv --track 5
音声トラック 5 はありません。この動画にあるのは:
  トラック 0: モノラル(ゲーム音)
  トラック 1: モノラル(マイク)
```

> **注意:** コマンド版でトラックを切り替えるときは、`--refresh-audio` も一緒に付けてください。前のトラックの音声が残っていると変更が反映されません。(画面版はここを自動でやってくれます)

### 困ったときは

- **「No module named 'numpy'」と出る** → `source venv/bin/activate` を実行し忘れています。行の先頭に `(venv)` が付いているか確認してください。
- **「ピークが検出されませんでした」と出る** → `--percentile 99` のように数字を下げて再実行してください。
