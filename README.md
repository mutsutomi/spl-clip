# spl-clip — 盛り上がった瞬間を自動で切り出すツール

長時間のゲーム録画などから、**音が大きく盛り上がった瞬間(歓声・叫び声・派手な効果音など)を自動で見つけて、その前後を短いクリップ動画として切り出す**ツールです。

「2時間の録画を全部見返してハイライトを探す」作業を、コマンド1回で済ませることを目指しています。

## こんなことができます

- 録画ファイル(.mov / .mp4 / .mkv など)を渡すと、音量が特に大きかった瞬間を自動で検出します
- 検出した瞬間の**前後60秒ずつ(合計約2分)** をクリップとして `clips/` フォルダに書き出します
- 切り出しは無劣化(再エンコードなし)なので、高速で画質も落ちません

## 準備(最初の1回だけ)

### 1. ffmpeg をインストールする

動画の処理に [ffmpeg](https://ffmpeg.org/) という無料ツールを使います。Mac なら「ターミナル」アプリを開いて、次の1行を貼り付けて Enter を押してください。

```bash
brew install ffmpeg
```

> `brew` が入っていないと言われた場合は、先に [Homebrew](https://brew.sh/ja/) をインストールしてください(公式サイトの手順どおりに1行実行するだけです)。

### 2. Python の環境を用意する

このツールは Python で書かれていて、`numpy` というライブラリを1つ使います。このフォルダ(`spl-clip`)でターミナルを開いて、次を順番に実行してください。

```bash
python3 -m venv venv
source venv/bin/activate
pip install numpy
```

> **venv とは?** このフォルダ専用の Python 環境です。パソコン全体を汚さずにライブラリを入れられます。

準備はこれで完了です。

## 使い方

### 毎回最初にやること

ターミナルでこのフォルダを開き、専用環境を有効にします。

```bash
cd spl-clip のフォルダの場所
source venv/bin/activate
```

(行の先頭に `(venv)` と表示されていれば OK です)

### ステップ 1: まずは候補を確認する(おすすめ)

いきなり切り出す前に、`--dry-run` を付けて「どこが検出されたか」だけを確認できます。

```bash
python3 auto_clip.py 録画ファイル.mov --dry-run
```

すると、こんな一覧が表示されます。

```
=== クリップ候補: 5 件 ===
  clip_001: 00:03:20 〜 00:05:20 (120秒)
  clip_002: 00:12:40 〜 00:14:40 (120秒)
  ...
```

### ステップ 2: 候補の数を調整する(必要なら)

- **候補が少なすぎる** → 検出の基準をゆるめます

  ```bash
  python3 auto_clip.py 録画ファイル.mov --dry-run --percentile 99
  ```

  `--percentile` は「音量が上位何%なら盛り上がりとみなすか」の設定です。標準は 99.5(上位 0.5%)。**数字を小さくするほど候補が増えます**(99 → 上位 1%)。

- **候補が多すぎる** → 逆に数字を大きくします(例: `--percentile 99.8`)。

納得のいく候補数になるまで、`--dry-run` のまま何度でも試してください。2回目以降は音声の解析結果を使い回すので、すぐに結果が出ます。

### ステップ 3: 切り出しを実行する

`--dry-run` を外して実行すると、実際にクリップが書き出されます。

```bash
python3 auto_clip.py 録画ファイル.mov
```

完了すると `clips/` フォルダに次のようなファイルができます。

```
clips/
  clip_001_000320.mp4   ← 「00:03:20 から始まるクリップ」という意味
  clip_002_001240.mp4
  ...
```

## よく使うオプション

| オプション | 意味 | 標準値 |
|---|---|---|
| `--dry-run` | 切り出さず、候補の一覧だけ表示する | — |
| `--percentile 99` | 検出のしきい値。小さくすると候補が増える | 99.5 |
| `--before 30` | 検出した瞬間の何秒**前**から切り出すか | 60 |
| `--after 30` | 検出した瞬間の何秒**後**まで切り出すか | 60 |
| `--gap 30` | 盛り上がり同士がこの秒数以内なら1本のクリップにまとめる | 10 |
| `--track 1` | 使う音声トラックの番号(下記参照) | 0 |
| `--refresh-audio` | 音声の解析キャッシュを作り直す | — |

例: 「前後30秒ずつの短めクリップにしたい」場合

```bash
python3 auto_clip.py 録画ファイル.mov --before 30 --after 30
```

## OBS のマルチトラック録画を使っている場合

OBS で「ゲーム音」と「マイク音」を別トラックに分けて録画している場合、標準ではトラック 0(多くの場合ゲーム音側)で検出します。**自分の声(実況の叫び)で検出したい**ときは、マイクのトラック番号を指定してください。

```bash
python3 auto_clip.py 録画ファイル.mov --track 1 --refresh-audio
```

> トラックを切り替えるときは、必ず `--refresh-audio` も一緒に付けてください。前のトラックの解析キャッシュが残っていると、変更が反映されません。

## フォルダの説明

| フォルダ | 中身 | 消していい? |
|---|---|---|
| `clips/` | 完成したクリップ動画(成果物) | 必要なものを残して整理 OK |
| `cache/` | 検出用の音声ファイル(作業用) | いつ消しても OK(次回また自動で作られます) |

## 困ったときは

- **「ffmpeg が見つかりません」と出る** → 準備の手順 1 を実行してください。
- **「No module named 'numpy'」と出る** → `source venv/bin/activate` を実行し忘れています。行の先頭に `(venv)` が付いているか確認してください。
- **「ピークが検出されませんでした」と出る** → `--percentile 99` のように数字を下げて再実行してください。
- **クリップの開始位置が数秒ズレる** → 無劣化切り出しの仕様上、カット位置が動画のキーフレーム単位に丸められるためです。正確さより速度と無劣化を優先しています。
- **静かな場面ばかり検出される** → BGM や環境音の大きい録画では起こりがちです。OBS でマイクを別トラックにして `--track` で指定すると、自分の声だけで検出できて精度が上がります。
